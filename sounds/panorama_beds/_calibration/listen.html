grand_library · loop calibration · 4 takes

Each file is an independent 30s ElevenLabs generation of the grand_library prompt with loop: true, returned in a different format. Different content, different seams — pick the winner on authorial fit + seam cleanness + codec transparency.

Listening checklist per take

  • Authorial fit: does it sound like a beit midrash? Hebrew/Aramaic murmur, page turns, wooden benches, stone reverb? Any wrong cues (music, shouting, modernness)?
  • Seam: click Jump to seam (-2s) to hear the last 2 seconds flowing into the first (with loop on). A click or drop there = bad seam.
  • Codec transparency: MP3 128 vs 192 vs Opus 128 vs PCM lossless — can you hear compression artifacts? PCM is the reference.

Note on Safari + Opus

Opus in <audio> may not play in Safari (version-dependent). If the Opus row is silent, try Chrome or Firefox. The frontend's final playback uses Web Audio decodeAudioData, which has broader Opus support than plain <audio>.
